# СветДом — интернет-магазин освещения

Учебный проект: адаптивная главная страница интернет-магазина светильников, созданная на HTML, CSS и JavaScript без сборщика и сторонних зависимостей.

## Что сделано

- Добавлены шапка сайта, навигация и каталог категорий освещения.
- Создан главный промобаннер с изображением LED-люстры.
- Добавлены карточки популярных товаров с ценами, наличием и кнопками.
- Реализованы поиск по карточкам, добавление товара в корзину и переключение избранного.
- Настроена адаптивная верстка для компьютеров, планшетов и телефонов.
- Оформлены блоки преимуществ, информация о магазине и контакты.

## Запуск локально

Откройте PowerShell в папке проекта и выполните:

```powershell
npx.cmd --yes http-server . -p 8000
```

Затем откройте http://localhost:8000/. Для остановки сервера нажмите `Ctrl+C`.

Главное изображение баннера загружается с сайта Wayfair и требует подключения к интернету.
